*Weather App*  
A lightweight, responsive frontend web application developed using HTML5, CSS3, and JavaScript (ES6+). The app allows users to search for any city and instantly retrieve real-time weather data, including temperature, humidity, wind speed, and current conditions.

*Key Features:*  
- *API Integration*: Fetches live weather data using a RESTful weather API.  
- *Responsive UI*: Mobile-first design ensures seamless experience across devices.  
- *Error Handling*: Validates user input and gracefully handles invalid city names or API failures.  
- *Clean Code Structure*: Demonstrates best practices in DOM manipulation, event handling, and asynchronous JavaScript.

This project showcases core frontend development skills including asynchronous API calls, dynamic UI updates, and responsive design principles, making it ideal for demonstrating proficiency in modern web fundamentals.

*Setup Instructions*

1. Download or clone the project files.
2. Open the project folder in Visual Studio Code.
3. Ensure the "index.html" file is present in the project directory.
4. Open "index1.html" in a web browser or run it using the Live Server extension in VS Code.
5. Enter a city name in the input field and click the Search button to view the weather information.

Requirements

- Any modern web browser (Chrome, etc).

No additional installations or dependencies are required.
